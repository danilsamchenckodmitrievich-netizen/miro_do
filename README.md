# Miro Do

Онлайн-доска в стиле Miro: бесконечный холст, стикеры, фигуры, стрелки, текст, рисование, картинки.
Совместная работа в реальном времени через Supabase. Без сборки: обычные HTML, CSS и JS.

## Запуск

```bash
python -m http.server 5173
```

Откройте http://localhost:5173. У каждой доски своя ссылка: id доски записан в адресе после `#`.

## Совместная работа (Supabase)

1. Создайте проект в Supabase и выполните [supabase/schema.sql](supabase/schema.sql) в SQL Editor.
2. Впишите URL проекта и publishable (anon) ключ в [config.js](config.js).
3. Отправьте ссылку на доску коллегам: все увидят изменения и курсоры друг друга.

Без настроек доска работает офлайн и сохраняет всё в браузере.

## Возможности

- Стикеры, прямоугольники, круги, ромбы, текст, стрелки (прилипают к объектам), карандаш, ластик
- Картинки: кнопка, Ctrl+V или перетаскивание файла
- Выделение рамкой, перемещение, изменение размера, слои, дублирование, копирование между досками
- Отмена и повтор, мини-карта, масштаб колесом и щипком, экспорт и импорт в JSON
- Онлайн-курсоры и список участников

Горячие клавиши показаны по кнопке `?` внизу слева.
