# Miro Do

Онлайн-доска, где совмещены Miro и Obsidian Canvas: бесконечный холст, карточки с Markdown и формулами,
изогнутые связи между карточками, группы, стикеры, фигуры, рисование, ссылки на сайты и файлы.
Совместная работа в реальном времени идёт через Supabase. Сборка не нужна: только HTML, CSS и JS.

## Запуск

```bash
python -m http.server 5173
```

Откройте http://localhost:5173. У каждой доски своя ссылка, её id записан в адресе после `#`.

## Возможности

**Как в Obsidian Canvas**
- Карточки с Markdown: заголовки, списки, `==выделение==`, задачи `- [ ]` (отмечаются кликом), таблицы, код, формулы `$…$` и `$$…$$`
- Связи: потяните за точку на краю карточки. Если отпустить на пустом месте, появится новая карточка
- Связи бывают кривыми, прямыми или ломаными, с подписью, цветом и стрелками на одном или обоих концах
- Группы с названием двигаются вместе со всем, что лежит внутри
- 6 цветов как в Obsidian
- Экспорт и импорт файлов `.canvas` (формат JSON Canvas), чтобы открывать доску в Obsidian

**Как в Miro**
- Стикеры, текст, прямоугольники, круги, ромбы, карандаш, ластик
- Выделение рамкой, изменение размера, слои, дублирование, копирование между досками
- Майнд-карта: Tab создаёт связанную карточку
- Мини-карта, поиск (Ctrl+F), масштаб колесом мыши и щипком, привязка к сетке
- Онлайн-курсоры и аватары участников, кнопка «Поделиться»
- Список моих досок, переименование, светлая и тёмная тема

**Ссылки и файлы**
- Вставьте ссылку через Ctrl+V или кнопку с глобусом. YouTube, Vimeo, Figma, Google Docs, Spotify и другие сайты встраиваются прямо в доску
- Перетащите или вставьте файл: картинки, PDF (открывается внутри), видео, аудио, `.md`, `.txt` и любые другие файлы

## Совместная работа (Supabase)

1. Создайте проект в Supabase и выполните [supabase/schema.sql](supabase/schema.sql) в SQL Editor.
2. Впишите URL проекта и publishable (anon) ключ в [config.js](config.js).
3. Отправьте ссылку на доску коллегам: все увидят изменения и курсоры друг друга.

Без настроек доска работает офлайн и сохраняет всё в браузере (IndexedDB).
